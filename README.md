# MedPazyl Гистология

Гистология оқу сайты (статикалық): алдымен курс таңдалады — 1 курс «Гистология негіздері және адам эмбриологиясы» (17 тақырып), 2 курс «Ас қорыту жүйесінің гистологиясы» (15 тақырып). Vercel арқылы жариялауға дайын.

- `index.html` — сайт
- `data/` — мазмұн (JSON): `g01–g17` — 1 курс, `t01–t15` — 2 курс; конспект, препарат талдау, карталар, тест
- `img/` — микросуреттер (Юй Р.И., Абильдинов Р.Б. атласы) және схемалар (Афанасьев оқулығы)

Кіру: Telegram (@nurmedacademy) немесе Instagram (@nurassyl.medicine) парақшасына жазылу батырмасы арқылы.
