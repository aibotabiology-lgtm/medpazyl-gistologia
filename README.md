# MedPazyl Гистология

Ас қорыту жүйесінің гистологиясы — оқу сайты (статикалық). Vercel арқылы жариялауға дайын.

- `index.html` — сайт
- `data/` — 15 тақырыптың мазмұны (JSON): конспект, препарат талдау, карталар, тест
- `img/` — микросуреттер (Юй Р.И., Абильдинов Р.Б. атласы) және схемалар (Афанасьев оқулығы)

Кіру: Telegram (@nurmedacademy) немесе Instagram (@nurassyl.medicine) парақшасына жазылу батырмасы арқылы.
